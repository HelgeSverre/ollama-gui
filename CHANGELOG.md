# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.6] - 2026-11-09

### Changed

- **Dependencies**: Updated 17 runtime and development dependencies (#93).
- **Model catalog**: Refreshed the Ollama library snapshot from 260 to 270 models, with no removals (#89).
- **Model catalog**: Updated pull counts, sizes, and capabilities of existing models.

### Added

- **Model catalog**: Added `lfm3`, `lfm3-omni`, `mimo-v2.6`, `lfm3-vl`, `lfm3-audio`, `autotrust-jev`, `pplx-decider-flash`, `kimi-k3.1-pro`, `mimo-v2.6-flash`, and `mimo-v2.6-pro`.

## [2.0.5] - 2026-10-23

### Changed

- **Dependencies**: Updated minor-and-patch dependencies (10 updates)

### Added

- **Model catalog**: Added new models: `bonsai-2`, `beam`, `d1`, `nemotron-3.5-super`, `nemotron-3.5-bolt`, `pplx-decider`, `muse-spark-open`, `d1-omni`
- **Model catalog**: Additional models added in refresh: `minimax-m3.1-flash`, `flint`, `d3`, `phonon`

### Data

- **Model catalog**: Refreshed Ollama library snapshot from 256 to 260 models
- **Model catalog**: Updated pull counts, sizes, and capabilities of existing models
